# Stanford: ML for multimodal biology

*Remote contributor at the Gaudillière lab, Stanford School of Medicine, since August 2026.*

## Context

The lab develops machine learning methods to identify **sparse biomarkers** of clinical problems (postoperative recovery, birth complications, and others). The data are high-dimensional and heterogeneous, with few samples compared to the number of features, so the main risk is a result that is only noise.

## What I work on

High-dimensional ML on multimodal data (electroencephalograms, MRI, proteome, and others). This includes:

- **Feature selection with Stabl**: artificial (knockoff) features are generated to set a data-driven noise threshold, and only features above it are kept.
- **Integration of expert prior knowledge with iEN** (immunological elastic net).
- **Optimal transport models for single-cell digital twins** (CellOT), used to move from single-cell data to patient-level features.
- **Classical regularization techniques** on high-dimensional data.
- **Multimodal integration.**
